One letter: **Z** — for "zero sleep", the word behind the letter describing the day. This is the whole entry for make.fun's "One Letter for Your Day" bounty: the program writes exactly one character, Z, to the output file. Nothing else — no word, no gloss, no punctuation, no trailing newline.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` (exactly 1 byte, `Z`) into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
